📄 Intelligent Resume Analyzer & Candidate Ranking System

An intelligent web-based application designed to analyze resumes against job descriptions, evaluate candidate suitability, identify skill gaps, and rank candidates based on their relevance to job requirements.

🚀 Project Overview

The Intelligent Resume Analyzer helps job seekers understand how well their resumes match specific job opportunities. It also provides recruiters with tools to analyze and compare multiple candidates efficiently.

The system generates matching scores, identifies relevant and missing skills, and provides actionable recommendations to improve resume quality.

✨ Key Features

- Resume Upload: Upload resumes in PDF and DOCX formats.
- Job Description Analysis: Enter job descriptions to evaluate candidate suitability.
- Match Score: Generate a resume-job description compatibility score.
- Skill Analysis: Identify matched skills and missing skills.
- Improvement Recommendations: Provide suggestions to improve resume relevance.
- Visual Analytics: Display analysis results using interactive charts and radar visualizations.
- PDF Reports: Generate downloadable resume analysis reports.
- Analysis History: Access previously analyzed resumes and results.
- HR Candidate Ranking: Upload multiple resumes and rank candidates according to job requirements.

⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/AJAY-ES7/resume_analyzer.git
cd Resume-Analyzer

2. Create a virtual environment

python -m venv venv

3. Activate the virtual environment

Windows:

venv\Scripts\activate

Linux / macOS:

source venv/bin/activate

4. Install dependencies

pip install -r requirements.txt

5. Run the application

python app.py

Open your browser and visit:

http://127.0.0.1:5000/
